# Python Dersleri ve Örnekleri

Bu depo, Python programlama dilinin temel ve ileri konularını kapsayan ders notları, kod örnekleri, ödevler ve nesneye yönelik programlama (OOP) müfredatını içerir.

## İçerik

- **Ders Dosyaları**: `ders1.py` - `ders6.py` - Python'un temel kavramlarını (veri türleri, operatörler, koşullar, döngüler, fonksiyonlar, recursive fonksiyonlar) kapsar.
- **Ödevler**: `odev1.py` - `odev4.py` - Ders konularına dayalı pratik ödevler.
- **OOP Müfredatı**: `oop_mufredat.md` - Nesneye yönelik programlama konularının madde madde listesi.
- **İlk Periyot Çalışmaları**: `ilk_periyot_calismalari/` klasörü altında ek ders ve alıştırma dosyaları.
- **Diğer**: `robot_soccer.py`, `stick_men.py` gibi örnek projeler.

## Gereksinimler

- Python 3.x

## Çalıştırma

Her bir `.py` dosyasını Python yorumlayıcısı ile çalıştırabilirsiniz:

```bash
python ders1.py
```
